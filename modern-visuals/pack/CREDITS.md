# Modern Terrain Starter

The six texture files in this pack are derived only from ambientCG materials,
licensed under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The provider explicitly permits redistribution of downloadable files, including
inside games: [ambientCG license information](https://docs.ambientcg.com/license/).

| Surface | Source | Included maps |
| --- | --- | --- |
| Dirt | [Ground067](https://ambientcg.com/a/Ground067) | Color and DirectX normal |
| Worn dirt path | [Ground103](https://ambientcg.com/a/Ground103) | Color and DirectX normal |
| Forest floor | [Ground106](https://ambientcg.com/a/Ground106) | Color and DirectX normal |

Technical processing: 2K source maps encoded as legacy DXT1 DDS with twelve mip
levels; color mips averaged in linear light; normal mips averaged as vectors and
renormalized. No recoloring, invented artwork, roughness conversion or shader
replacement is included. Sources, member hashes and output hashes are recorded
in the manifest and the repository's sources.lock.json.

Created using Ground067, Ground103 and Ground106 from ambientCG.com.
No Bethesda artwork, source texture pixels, meshes, plugins or game files are
included. The texture filename targets are compatibility metadata only.
